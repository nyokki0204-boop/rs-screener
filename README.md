# セクターの流れ / RS Screener

QQQに対するセクター・テーマの強さと、その週次変化を確認するStreamlitアプリ。

## 起動

```sh
pip install -r requirements.txt
streamlit run app.py
```

- 日本語名（ティッカー）表示、改善・維持・悪化のサマリー
- 総合RSと前週差の強弱マップ、直近6週の軌跡
- 4・13・26・52週RS、ETF騰落率、比較対象をそろえた順位変化
- 任意のETFを選択した対QQQ相対推移、CSV出力
- セクター／株式テーマ／コモディティを分離

総合RSは元の4期間等加重を維持。週次履歴は調整後日足から再計算し、アプリを開いた頻度に依存しません。既存の `data/rs_history.csv` は変更・削除せず、計算には使用しません。`app.py2` は以前の参考版で起動対象ではありません。

確定週足にはNYSEカレンダーの週最終取引日を使用。暫定モードでも終了済みの日足のみを使います。週ラベルは金曜日、実際の価格基準日は別表示。53週に欠損があるETFは除外し、欠損を過去価格で補完しません。

強弱マップは独自定義でJdK RRGではありません。横軸=(総合RS−1)×100、縦軸=総合RSの前週差×100。±0.20ptの横ばい基準は表示上の目安。資金フローや売買シグナルの推定ではありません。

## 検証

```sh
pip install pytest
python -m pytest -q
```

確定／暫定週、Good Friday、欠損、相対強度の計算、模擬データによるStreamlit操作を検証します。ライブデータはYahoo Financeの可用性に依存します。
